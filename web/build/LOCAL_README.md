# MediaLab 本地网页版

双击 `启动本地网页版.cmd`。无需安装 Node.js 或其他依赖，不需要管理员权限。

本地服务仅监听 `127.0.0.1:17861`，自动使用默认浏览器打开页面。关闭命令行窗口即可停止。
媒体内容只在浏览器本地读取，不上传。HEVC 播放依赖浏览器 WebCodecs 支持；推荐使用当前系统支持 HEVC 的浏览器，或使用 Windows 版。

视频和帧大小图同屏显示，拖动中间分隔栏调整高度；“码流信息”和“帧明细”可展开。左右 Compare 各自显示对应帧图，点击帧图会暂停定位。
以非关键帧开头的文件，浏览器从首个可用关键帧播放；前面的帧统计仍保留。

V0.0.8：视频结构分析在后台 Worker 执行，显示读取/分析阶段的近似进度。返回首页会取消任务、释放会话数据，再次加入相同文件会重新解析。
